# Third-party components

The repository contains research code adapted from the CT-CLIP ecosystem:

- `src/ct_clip/` — CT-CLIP model components;
- `src/transformer_maskgit/` — CTViT/MaskGIT components used by CT-CLIP.

Primary reference:

> Ibrahim Ethem Hamamci, Sezgin Er, et al. “Developing Generalist Foundation
> Models from a Multimodal Dataset for 3D Computed Tomography”, 2025.
> [arXiv:2403.17834](https://arxiv.org/abs/2403.17834)

Before redistributing the project or using it commercially, review the licenses
and terms of the original model code, checkpoints and datasets. This repository
does not relicense third-party assets.
